DevHive OAuth Testing Guide

  • Open a mock client (HeyBleepi, Hershive, SocMed3) from the Test Suite.
  • Click "Login with DevHive" to start the OAuth flow.
  • Authorize or deny access on the DevHive consent page.
  • Observe token exchange and API calls in the mock client UI.
  • Use the API Call Tester for direct endpoint testing.
  • Try error scenarios: deny consent, use invalid/expired tokens, test rate limits.
  • Check the logs and debug panels for request/response details.

For more scenarios, see OAuth Test Scenarios.
