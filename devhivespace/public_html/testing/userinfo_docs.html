Userinfo API Documentation

Endpoint: /api/oauth/userinfo.php
Method: GET or POST
Headers: 
Authorization: Bearer <access_token>
Optional Query: 
?fields=username,email,profile_picture
Success Response: 
{
  "success": true,
  "data": {
    "id": 123,
    "username": "johndoe",
    "email": "john@example.com",
    "profile_picture": "https://devhive.com/uploads/avatars/123.jpg",
    "created_at": "2024-01-15T10:30:00Z"
  }
}
Error Response: 
{
  "success": false,
  "error": "invalid_token",
  "error_description": "The access token provided is expired or invalid",
  "error_code": "TOKEN_EXPIRED"
}
